## English

### Notes from your meetings, written by a model you choose

- Diduny writes notes from a meeting or voice note: summary, decisions, action items and open questions. A model on this Mac, Claude Code, Codex or Gemini CLI on your own subscription, or an API key writes them.
- Your AI agents can read your meetings: install the diduny command in Settings > General > Agents, and Claude Code or Codex learns how to search and quote them.
- New sliders for playback and audio levels, and the paste animation is back.

## Українською

### Нотатки зустрічей від моделі, яку ви оберете

- Diduny пише нотатки із зустрічі чи голосової нотатки: підсумок, рішення, завдання й відкриті питання. Пише модель на цьому Mac, Claude Code, Codex чи Gemini CLI за вашою підпискою або API-ключ.
- Ваші ШІ-агенти можуть читати зустрічі: встановіть команду diduny в Налаштування > Загальні > Агенти, і Claude Code чи Codex навчиться шукати й цитувати їх.
- Нові повзунки для відтворення й рівнів звуку, і повернулася анімація вставлення.
