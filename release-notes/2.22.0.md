## English

### Steadier processing you can see, and diagnostics you can send

- Recordings on Diduny Cloud no longer wait behind Whisper on this Mac, Recordings, Notes and the menu show what is being transcribed, and notes start as soon as a meeting is transcribed. Failed automatic notes are tried again later.
- Quitting or a crash no longer loses work in progress: Diduny picks up cloud jobs and queued recordings at the next launch. Agents can now add to notes, tag recordings by project and link people when you ask.
- Something went wrong? Help → Export Diagnostics… saves a file for support, with no audio or text. Diduny now counts which features are used, anonymously (Settings → Account to turn off), and ElevenLabs keys restricted to Speech to Text work.

## Українською

### Надійніша обробка, яку видно, і діагностика, яку можна надіслати

- Записи в Diduny Cloud більше не чекають, поки Whisper закінчить на цьому Mac, «Записи», «Нотатки» і меню показують, що зараз транскрибується, а нотатки починаються одразу після транскрипції зустрічі. Невдалі автоматичні нотатки Diduny повторює пізніше.
- Вихід із Diduny чи збій більше не губить роботу: під час наступного запуску Diduny продовжує хмарні завдання і чергу. Агенти на ваше прохання доповнюють нотатки, ставлять проєкт і теги та додають людей до записів.
- Щось пішло не так? Help → «Експортувати діагностику…» зберігає файл для підтримки, без аудіо й тексту. Diduny тепер анонімно рахує, якими функціями користуються (вимкнути: Налаштування → Акаунт), а ключі ElevenLabs, обмежені до Speech to Text, працюють.
