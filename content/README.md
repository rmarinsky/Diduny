# content/

Сховище контент-системи Дідуні та йой!: календар, драфти, черги тем і тижневі звіти. Пишуть сюди три заплановані задачі Claude і Роман.

Гілка `content/drafts` ніколи не зливається в `main`. Не відкривай з неї pull request: він запустить macOS CI на кожен коміт.

| Шлях | Що там |
|---|---|
| `calendar.md` | спільний календар: хто з продуктів володіє днем |
| `rejections.md` | відхилені теми з причиною |
| `weekly/` | тижневі звіти |
| `diduny/` | драфти, черга і банк тем Дідуні |
| `yoy/` | драфти, черга йой!; сюди ж копії бази знань і банку тем з репозиторію йой! |
