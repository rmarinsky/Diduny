Flow

  1. User dictates. The response has hints, so Diduny does not paste.
  2. The panel shows the text with marked sentences and the hints.
  3. User clicks Paste (Return) to paste anyway, or Copy, or Esc to drop it.
  4. Text without hints pastes as now.

The only option that catches the sentence before it is sent, but it adds a click to each flagged dictation and breaks auto paste and force submit.

API, same for all three options

Request adds language. The server returns hints only when simplify is true and the language is English. Offsets are UTF-16 code units into the returned text, so Swift can make an NSRange from them. Option 2 also stores the hints with the transcript version. No option needs a second call. All three need one opt-in setting that turns on simplify.
